# Security

The window makes no network connections and runs `infer.py` with an argument list (no shell), but bugs happen.

If you think you found a security problem, please use GitHub's **private** reporting: open the repository's **Security** tab and
choose **Report a vulnerability**. Please don't post exploit details in a public issue. This is a hobby project, so expect
a reply in days, not hours.

Never include real passwords, tokens or personal files in a report.
